# GIFs de ejercicios

Guarda aquí los GIFs usados por la biblioteca.

Los nombres esperados están definidos en `exercise-library.js`.

Ejemplos:

- `bench-press.gif`
- `cable-chest-fly.gif`
- `lat-pulldown.gif`
- `lateral-raise.gif`
- `back-squat.gif`

Si un GIF todavía no está cargado, la aplicación seguirá funcionando y mostrará en el popup la ruta exacta del archivo faltante.

Usa únicamente archivos propios o con licencia/permiso suficiente para publicarlos en tu repositorio.
